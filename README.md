# Sticky Notes Pro

Rust 原生的桌面便签应用。每张便签都是一个独立小窗口，支持正文加粗、有序 / 无序列表、自动保存、撤销重做和七种背景颜色。

## 特性

- **列表编辑**：段落开头输入 `1. ` 得到有序列表，`- ` 或 `* ` 得到无序列表
- **自动保存**：不需要手动保存。`Ctrl+S` 可立即提交保存或重试失败的便签
- **外观**：跟随系统 / 浅色 / 深色三档，支持自定义背景配色（白 / 黑固定）；Windows 边框由系统管理，Linux 支持自定义边框配色
- **回收站**：删除的便签保留在“已删除”里，可以恢复，也可以逐条彻底删除（需确认，不可撤销）

## 加粗

点击便签右上角最左侧的 **B** 按钮，或按 `Ctrl+B`：

- 选中文字时统一加粗；如果选中文字已经全部加粗，则取消加粗。
- 没有选中文字时切换后续输入的加粗状态，按钮高亮表示开启；再按一次关闭。
- 支持撤销 / 重做。复制粘贴只传递纯文本，粘贴使用当前输入样式；`**文字**` 不会自动转换为加粗。

## 运行

```sh
cargo run --release
```

开发时可指定独立数据目录，避免混入日常便签：

```sh
# Linux / macOS
STICKY_NOTES_DATA_DIR=$(mktemp -d) cargo run

# Windows PowerShell
$env:STICKY_NOTES_DATA_DIR = "$env:TEMP\sticky-notes-pro-dev"; cargo run
```

## 数据保存在本机

不联网，所有内容只写本地：

- 便签正文、颜色、窗口位置与启动状态 → 数据目录的 `app.db`（SQLite）
- 全局设置（外观、缩放、字体、默认尺寸） → 配置目录的 `settings.json`

路径由操作系统标准目录决定，见 [paths.rs](src/persistence/paths.rs)。
设置 `STICKY_NOTES_DATA_DIR` 后，数据库、设置与单实例锁都放在该目录；同一目录同一时间只运行一个实例。

新建空白页只是草稿，有非空内容后才保存为便签；已保存的便签允许清空，不会自动删除或弹出删除确认。

## 常用快捷键

| 操作                | 按键                                                  |
| ------------------- | ----------------------------------------------------- |
| 新建便签            | Ctrl+N                                                |
| 打开 / 激活便签列表 | Ctrl+Shift+L                                          |
| 打开 / 激活设置     | Ctrl+,                                                |
| 保存 / 重试保存     | Ctrl+S                                                |
| 关闭当前便签        | Ctrl+W                                                |
| 置顶 / 取消置顶     | Ctrl+Shift+P（平台支持时）                            |
| 加粗 / 取消加粗     | Ctrl+B                                                |
| 撤销 / 重做         | Ctrl+Z / Ctrl+Shift+Z（Windows、Linux 另支持 Ctrl+Y） |

macOS 使用 Cmd。编辑、导航与列表操作的完整按键见设置 → 快捷键；当前版本不支持改键和系统级全局快捷键。关闭最后一个窗口即退出，下次启动恢复最后关闭的已保存便签，否则打开空白草稿。
