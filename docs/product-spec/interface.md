# 界面、外观与便签管理

[规格入口](../product-spec.md)

## 便签标题栏与状态

便签使用自定义标题栏，左侧留空供拖动；右侧顺序固定为：Pin、菜单、最小化、最大化 / 还原、关闭。最小化和最大化紧挨关闭左侧。

- 图标使用随应用打包的 SVG 等资源，不依赖特殊字体字符；悬浮显示描述。
- 空白区支持拖动、双击最大化 / 还原，按钮点击不能触发拖动或双击。
- 菜单提供文字入口“设置”“便签列表”和背景颜色选择卡，没有便签快速切换按钮。
- 菜单紧贴七色色卡，“背景颜色”标题紧靠色卡，仅保留对称内边距，不因拉伸留下空白。
- 选择颜色立即应用并关闭菜单；取消、点击外侧或 Escape 不改变颜色。
- 保存状态固定在便签右下角，字号小、视觉弱；长错误可通过提示或错误区域完整查看，不影响正常编辑。
- 最小窗口尺寸下所有窗口操作仍应可用；布局确有需要时可使用溢出入口，但 Pin 与关闭保持直接可操作。

列表与设置使用系统标题栏或框架默认装饰，以实现简单为准。平台限制见[窗口规范](windows.md)。

## 背景颜色与全局外观

`theme_id` 属于便签内容，使用稳定语义 id：`white`、`yellow`、`green`、`pink`、`purple`、`blue`、`gray`；不把当前 RGB / HEX 当成长期内容格式。

默认 `white`：浅色显示白底，深色显示近黑底。其他颜色各有保留颜色特征的浅 / 深色映射。便签、色卡、列表卡片共用映射，当前颜色有选中标记。

全局模式为“跟随系统”（默认）、“浅色”“深色”，覆盖便签、菜单、列表、设置与确认窗口。跟随系统时响应运行中的主题变化；无法判断时回退浅色。手动选择不随系统变化。

切换模式只改变展示，不改写便签 `theme_id` 或新便签默认颜色。未知 id 按 white 展示但保留原 id，不能以展示 fallback 覆盖数据。

便签改色立即同步列表并通过自动保存持久化。新便签默认颜色不影响已有便签。

背景、正文、选区、光标、图标、悬浮和危险操作样式成组切换，不能混用浅 / 深色前景和背景。所有正文及操作控件保持可辨认。

## 便签列表

- 正常视图只显示未删除、已入库的便签，按 `created_at DESC, id ASC` 稳定排序；编辑不使卡片跳动。
- 卡片显示自身背景、带列表标记的内容预览与保存状态，预览左对齐并从顶部展示。右侧操作按钮上方显示创建时间、最后修改时间，按本地时区展示为 `YYYY-MM-DD HH:mm:ss`；正常和已删除视图均显示。
- 卡片提供打开、删除入口；窗口提供新建、设置和已删除视图入口。
- 内容和颜色随内存编辑更新，不等数据库保存；连续输入可短间隔合并刷新，普通编辑只更新变化卡片，不重读全文或重建整个列表。
- 预览只读取显示所需的开头，允许截断；不能用无编号的搜索投影代替展示投影。
- 空草稿不显示为已保存便签；首次入库、软删除、恢复和彻底删除成功后同步相应列表。
- 已删除视图按 `deleted_at DESC, id ASC` 排序，显示预览和删除时间；蓝色背景“恢复”、红色背景“彻底删除”与卡片明显区分。
- 删除图标与文字水平居中对齐。

正常 / 已删除切换仍属于同一列表窗口。

## 空便签与删除

### 空草稿和已有便签清空

正文全部为空白（忽略生成编号 / 符号）时视为空。新草稿不入库，手动保存也不能保存空便签。

已有便签清空后先确认删除，不能自动删除。取消恢复清空前内容；确认软删除并保存清空前最后非空快照，包含尚未 autosave 的内容。成功前不移出正常列表。

### 软删除

正常列表的删除按钮执行软删除，没有批量清空或自动过期清理：

1. 对打开中的便签先处理 IME，冻结新编辑，捕获最新已提交内容。
2. 与 autosave 共用按修订顺序串行的保存队列，原子保存内容、投影、颜色、删除时间和窗口状态。
3. 成功后关闭目标编辑窗口，从正常列表移除；已删除视图同步加入。若最后窗口关闭，随后退出。
4. 失败保留窗口、列表与内存内容，解除编辑冻结并提示重试。

删除关闭窗口时记录它为最后关闭的便签；没有编辑窗口的列表删除不修改关闭记录。后到的旧 autosave 不能清除删除标记或复活便签。

格式不可读取的便签允许软删除，但只改删除元数据，保留原始 `document_json`、`plain_text`。删除不进入编辑撤销历史，使用已删除视图恢复。

### 恢复

恢复只清除 `deleted_at`，保留 id、内容、颜色和窗口状态；成功后回到正常列表，默认不打开编辑窗口，不改最后关闭记录。失败保留已删除状态并提示。

已删除便签不能直接编辑，需先恢复；恢复不会绕过打开时的内容格式校验，损坏内容仍只能进入错误 / 只读页面。

### 彻底删除

只允许逐条删除当前仍为软删除状态的目标 id，先展示预览和不可恢复警告，再二次确认。

队列接受后禁止重复提交、恢复和取消；便签、对应窗口状态、匹配的启动引用在同一事务移除。成功后移除卡片，不能从应用内恢复；失败全部回滚，保留记录并允许重试或取消。

不允许对正常便签执行彻底删除，也不提供批量清空。关闭列表不能使正在处理的确认或删除失去结果反馈。

## 设置

最多一个设置窗口，三个 Tab：

- 外观：跟随系统 / 浅色 / 深色、全局窗口字体 family / 字号，以及应用缩放。
- 便签设置：所有便签共用的字体 family / 字号，以及以后新便签的默认尺寸 / 颜色。
- 快捷键：按组展示当前固定快捷键，不提供改键；说明与[实际操作](shortcuts.md)一致。

三页均按内容需要支持滚动，最小尺寸下控件不被截断。窗口字体默认系统字体、基准字号 14 逻辑像素，允许 10–24；分组标题、辅助说明等保持相对字号层级，控件布局随之调整。正常尺寸下底部显示“取消 / 应用”；高倍率 / 小窗口时可随外层内容滚动访问。保存 / 未应用状态始终固定在右下角的小字号状态栏，长错误可完整查看。

窗口字体应用到菜单、列表、设置、确认框及便签界面文字，不改变正文的字体 / 字号。原生系统标题栏由系统控制，应用设置不改变它。字体名称与正文字体采用相同校验、缺失字体 fallback；保存成功后对已打开与新开窗口生效。

应用缩放默认 100%，硬性范围为 50%–250%（整数百分比）。界面输入和保存均禁止越界；旧设置缺省用 100%，手改配置中的非法 / 越界值回退 100% 并提示，不连带重置其他合法字段。缩放与系统 DPI 叠加，不替换系统 DPI，也不改写保存的窗口 / 正文字号。界面与正文按同一应用倍率展示，鼠标命中、滚动与 IME 候选位置使用一致的坐标变换；原生系统装饰不由应用缩放控制。

缩放作为设置草稿，写入成功后对所有新旧窗口生效；丢弃 / 取消不改变当前倍率。高倍率下内容允许滚动，但缩放控件及“应用”必须可到达，不能靠无限增大窗口最小尺寸避免布局问题。

默认尺寸只参与[新窗口继承链](windows.md#新便签尺寸与位置)，不调整已有窗口。默认颜色只作用于新便签；字体和字号应用到当前及以后打开的便签。

字号为 10–32 逻辑像素，默认 16；字体为空表示系统默认，字体缺失按正常 fallback 显示。字体名称去除首尾空白后不超过 200 个字符。默认尺寸必须为有限数值且至少 `320 × 240`，实际窗口结合可用工作区约束。

有未保存修改时切换 Tab，显示“保存 / 丢弃 / 取消”：保存成功或丢弃后才切换；取消留在原页；保存失败保留原页、修改与错误，允许重试。无修改直接切换。

设置只在写入成功后生效；丢弃恢复已保存值、不改变实际设置。取消 / 关闭设置页直接丢弃未应用修改并关闭。原子写入与损坏设置保护见[存储规范](storage.md#全局设置)。
