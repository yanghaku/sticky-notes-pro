# 技术职责与性能约束

[规格入口](../product-spec.md)

## 技术基线

Rust、Slint、cosmic-text、自定义轻量 Editor Core、SQLite 与 JSON 设置。依赖版本以 [Cargo.toml](../../Cargo.toml) / Cargo.lock 为准，不在产品文档复制版本清单。

- Rust：生命周期、编辑命令、保存协调、数据模型与平台封装。
- Slint：窗口与控件、输入桥接、界面展示。当前 winit 后端与 software renderer 的选择见 [main.rs](../../src/main.rs)。
- cosmic-text：字形整形、字体 fallback、排版、光标位置与命中映射；不是完整富文本编辑器。
- Editor Core：Document、结构变换、光标 / 选区与历史的唯一权威。
- SQLite：内容与应用状态；JSON：全局设置。权威来源与事务边界见[存储规范](storage.md)。
- Wayland 剪贴板复用 Slint / winit 原生 display 与 seat 的标准协议，不依赖 data-control、XWayland 或外部命令；Windows / X11 保留 arboard。固定 Slint 版本的内部桥接隔离在 `platform.rs`，升级时复核；上游同步读取缺少超时的差距记录在开发待办。

UI 的输入事件转换为 Editor 命令，排版映射必须回到同一文档位置。

## 当前模块职责

| 路径 | 职责 |
|---|---|
| `src/app/` | 应用所有权、窗口、输入、列表、设置、确认、保存维护与回复处理 |
| `src/editor/` | 普通输入、导航、历史、列表与跨单元结构操作 |
| `src/model.rs` | 版本化文档、校验、编号及各类投影 |
| `src/text_layout/` | 排版、几何 / 命中、共享字体和字形缓存、栅格绘制 |
| `src/persistence/` | 路径、设置、Schema / 迁移、窗口状态与便签事务 |
| `src/worker.rs` | 有界串行保存队列、修订顺序与任务回复 |
| `src/platform.rs`、`src/instance.rs` | 窗口能力与系统桥接、数据目录单实例 |
| `src/shortcuts.rs` | 固定便签操作绑定与设置页说明 |
| `ui/` | 便签、列表、设置、确认窗口、公共控件和外观；`app.slint` 为导出入口 |

按职责拆分，不为了目录形式增加无用层；具体文件名可调整，但职责边界和产品契约不能随意改变。

## 性能与资源约束

- 字体数据库、加载资源和字形栅格缓存由应用持有，多便签共享；每个窗口保留独立排版、选区、IME 和滚动状态。
- 输入触发合并绘制，不等待 50ms 保存维护周期；优先更新当前便签，不把磁盘保存和所有窗口轮询作为回显前置条件。
- 普通连续单行输入原地修改目标文本；合并输入不逐键创建全文撤销快照。导航与选择借用正文，不为读取光标位置复制文档。
- 保留新历史单元、IME、结构操作与清空恢复语义；不可通过删掉必要历史或丢弃未保存内容换速度。
- 未变化行复用排版，变化段重新整形；仅绘制可见文字。先测量布局和最终滚动位置，再生成一张不可变图像，避免光标跟随造成双绘。
- 字形缓存容量受限，增量统计并小批清退，不反复全表扫描或整体销毁热缓存。单张图像也有像素预算，不能因极端 DPI 无限分配。
- 列表预览有长度 / 行数边界，普通编辑局部更新稳定卡片模型；数据库结构刷新逐条生成预览，不能长期保留全部完整文档副本。
- 缓存可丢弃和重建，不能承担用户内容持久化职责。

当前新历史单元、IME 提交、删除等仍可能创建全文快照；长段落修改仍需该段重排，结构操作仍有全文路径。这些是当前的残余成本。

## 验证要求

真实桌面验证输入到回显、鼠标定位、跨行选区、滚动、列表换行、IME、DPI 和多窗口内存；区分事件处理、排版、图像提交与磁盘任务耗时。

未测平台明确记录未测；待验证场景维护在[开发待办](../development-status.md)。
