# 窗口生命周期与平台能力

[规格入口](../product-spec.md)

## 窗口与单实例

- 已创建的便签窗口按 `note_id` 唯一；重复打开激活已有窗口，不允许并发编辑同一便签。未创建便签的草稿窗口只有运行时标识。
- 便签列表、设置各有一个实例；重复请求激活原窗口。系统不允许抢焦点时采用平台允许的激活请求。
- 关闭便签只关闭窗口，不删除内容；关闭列表或设置不连带关闭其他窗口。
- 不提供显式退出。便签、列表、设置均参与最后窗口退出判断，没有托盘或无窗口后台模式。
- 菜单不属于顶层窗口。确认窗口不写入启动历史；有待处理的确认 / 保存操作时不能提前退出。
- 同一数据目录只允许一个可写实例。重复启动请求已有实例显示便签列表；通信失败提示问题，不另开可写实例。

窗口关闭需先处理 IME 并完成最新内容保存；失败与取消规则见[保存规范](storage.md#自动保存与关闭)。

## 启动恢复

启动只打开一个便签窗口，不恢复历史中的多窗口集合，也不自动打开列表或设置：

1. 最后成功关闭的是便签，且它仍存在、未软删除：打开该便签。
2. 最后关闭的是列表或设置：打开新的空草稿。
3. 首次启动、关闭记录无效、便签不存在或已删除：打开新的空草稿。

内容格式无法读取的有效便签仍打开错误 / 只读页面，保留数据，不以新便签覆盖它。
新草稿没有 `note_id`，首次非空保存才分配 id 并创建内容与窗口状态；空草稿关闭不制造便签或孤立窗口状态。已有便签恢复时允许空正文。

每次成功关闭已有便签、列表或设置，提交类型及适用的 `note_id`；空草稿关闭清除恢复目标，下次启动新草稿，不写便签或窗口状态。内容保存失败阻止的关闭不更新记录。状态记录失败或强制终止时，下一次启动仍使用上次成功持久化的记录。

## 每个窗口的状态

持久化窗口状态 id 为 `note:<note_id>`，辅助窗口 id 为 `notes_list`、`settings`。
状态字段及数据库约束见[持久化规范](storage.md#窗口与启动状态)。

- 保存正常尺寸、可用的坐标 / 显示器 / 缩放提示、最大化、Pin 偏好和最近使用时间。
- 正常尺寸是逻辑像素的内容区尺寸；最大化单独保存，不能用最大化后的尺寸覆盖正常矩形。
- 最小化只属于本次运行，不持久化；重开时正常显示或恢复最大化。
- 关闭便签后保留其状态，软删除也保留；彻底删除才移除。
- 是否打开由运行时管理，不存储 `is_open`，也不通过它决定启动恢复。
- Pin 是每个便签独立的偏好。不支持时禁用按钮并说明，不能因此覆盖原偏好。

## 新便签尺寸与位置

尺寸继承优先级：

1. 发起新建的便签窗口正常尺寸（若有）。
2. 本次运行最近激活的便签正常尺寸。
3. 最近使用 / 最近关闭的未删除便签的持久化正常尺寸。
4. 设置中的默认尺寸。
5. 内置默认尺寸 `360 × 420` 逻辑像素。

新便签不继承最大化或 Pin，默认正常、非置顶。最近使用由激活 / 成功关闭更新的 `last_used_at` 判断，不以内容保存时间代替。

支持坐标控制时，新窗口基于继承窗口向右、向下各偏移 20 逻辑像素；超出可用区域则重新放置。Wayland 由 compositor 放置，不要求 Cascade，也不借助特殊协议绕过限制。

## 平台能力与降级

| 能力 | Windows / Linux X11 | Linux Wayland |
|---|---|---|
| 基础输入、保存、多窗口 | 首发必须验收 | 首发必须验收 |
| 正常尺寸、最大化恢复 | 按系统能力恢复并验证 | 发出请求，以 compositor 结果为准 |
| 桌面坐标与 Cascade | 支持时恢复并验证 | 不要求，交给 compositor |
| Pin / Always On Top | 支持时提供并验证 | 后端支持才提供，否则禁用并说明 |

能力降级不包括基础编辑、IME、保存或剪贴板故障。不能把请求发出或按钮状态变化当成系统已成功执行。

恢复需处理显示器移除、分辨率与 DPI 变化；`monitor_id` 只是提示，不保证跨启动稳定。坐标可为负值，在平台层转换。

无效位置重新放置，保证完整标题栏和至少 `160 × 100` 逻辑像素编辑区可见；尺寸限制在可用工作区内，正常最小内容区为 `320 × 240`。工作区不足时以保留可操作区域为准，尺寸限制从宽。

恢复顺序：正常矩形、最大化请求、置顶请求。不支持的状态缺省或保留旧偏好，不阻止内容加载。
