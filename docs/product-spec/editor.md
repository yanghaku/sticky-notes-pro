# 文档模型与编辑行为

[规格入口](../product-spec.md)

## 文档与位置

当前支持 Paragraph、OrderedList、BulletList。列表项为结构化对象，编号 / 圆点由结构计算，不保存在正文中。Document、光标、选区和撤销历史由 Editor Core 统一管理。

- 文档至少有一个可编辑文本单元；全部删除后规范化为一个空 Paragraph。
- 段落与列表项正文不含结构性 CR / LF，硬换行通过拆分单元表达。视觉自动换行不改变文档。
- 独立有序列表从 1 开始；`continuation` 保留退出中间项后的编号关系。普通段落不计数，无序列表终止该连续关系。
- 只有显式新建独立列表才重启编号，不自动合并相邻列表。
- 位置为逻辑文本单元（段落 / 列表项）与 UTF-8 字节偏移；选区保留 anchor / focus。编号不是可单独编辑的文本。
- 光标始终处于有效字素边界，左右移动和字符删除按 grapheme cluster，不能拆坏组合字符或 Emoji。
- 结构变换移除无项列表，始终保留有效可编辑文档。

持久化格式及版本规则见[存储规范](storage.md#文档格式与投影)。首版不支持嵌套、任意起始编号或列表内软换行。

## 列表自动转换

普通 Paragraph 开头的精确半角前缀：有序列表 `1. `，无序列表 `- ` 或 `* `；无序统一显示圆点。

仅在直接输入最后一个空格、光标紧跟前缀且无活动选区时转换。可以保留前缀后的既有正文，并把光标放在列表项正文开头。

`2. `、`1)`、前置空格、全角变体不触发。粘贴、加载、Undo / Redo 不触发自动识别；IME 只在提交后评估，预编辑期间不转换。撤销转换恢复字面前缀，不立即再次转换。

## Enter

- 普通段落：在光标处分割为两个段落。
- 非空列表项：在光标处分割为两项，光标进入新项开头；项首创建前置空项，项尾续建空项。
- 正文长度为 0 的列表项：退出格式，原位置变成一个空 Paragraph，不额外插入段落。仅含空格的项不视为这种空项。
- 中间空项退出：保留前后所有项，拆成两侧列表块；有序后块保留 continuation。唯一项退出直接以 Paragraph 替换列表。
- 有选区先删除选区，再在折叠位置执行 Enter，整体可一次撤销。

## Backspace、Delete 与选区

- 正文内部 Backspace 删除前一个字素，Delete 删除后一个。
- 列表项正文开头 Backspace：无论是否为空，退出当前项的列表格式，保留正文，光标置于新 Paragraph 开头；剩余列表保留连续关系。
- 普通 Paragraph 开头 Backspace：与前一段落或前一列表的最后一项合并，保留前一单元类型，光标停在连接处。文档开头无操作。
- 单元末尾 Delete：与下一单元合并，保留当前类型；文档末尾无操作。空列表项的 Enter / Backspace 特殊规则优先。
- 有选区时只删除选区，折叠到范围起点，不再额外删字。跨单元删除保留两端未选文字，在起点合并并保留起点类型。
- 从某列表项开头选到下一项开头，删除前一完整项，后一正文保留；全选删除得到空 Paragraph。
- 选区替换、剪切采用相同删除规则；输入与粘贴替换是原子编辑命令。

编号即时派生：删除完整第 2 项，原第 3–6 项显示第 2–5 项；只清空第 2 项正文不改变项数。第 2 项开头 Backspace 退格式后，原第 3、4、5 项显示 2、3、4，不能全部变成 1。

插入、拆分、合并、删除及 Undo / Redo 后，编辑器、复制和列表预览使用同一编号规则。无序列表沿用相同结构编辑规则。

## Undo / Redo

- 历史按便签隔离，含 Document、光标、选区；重新打开不恢复历史。
- 每个便签最多 100 个历史单元，估算快照总量预算 32 MiB，淘汰最旧单元。至少保留最近操作，单个超大操作可超过预算。
- 同一位置连续插入且间隔不超过 1 秒可合并。移动 / 选择、删除、粘贴、Enter、列表变换和 IME 提交结束分组。
- 每次 IME 提交独立构成历史单元。
- 自动前缀转换保留字面前缀状态：第一次 Undo 只撤销转换，Redo 恢复列表；转换事件保留两个可回退状态。
- 新编辑清空 Redo。保存、预览刷新、窗口移动不进入历史；Undo / Redo 改变内容后照常自动保存。

已清空便签的确认 / 恢复按[便签管理](interface.md#空便签与删除)保留最后非空内容。

## 纯文本剪贴板

复制 / 剪切只处理选区，无选区不自动复制全文。复制保留列表当前标记；单元正文从偏移 0 开始被选中时包含标记，中途开始只复制所选正文。单元之间用 LF 连接。

剪切先成功写入系统剪贴板，再删除选区；写入失败不得删内容。错误恢复入口中的“复制全部内容”是独立操作。

Wayland 后端写入只确认请求送达，不能当作 compositor 已确认。剪切延后读取真实剪贴板 offer，内容一致且原窗口、修订与选区均未变化才删除；有限重试仍无法确认则保留正文并提示，组合输入 / 关闭中不执行延后删除。

粘贴仅接受纯文本，CRLF / CR 归一为 LF，再替换选区；不处理 HTML、RTF 或富文本格式。

每个 LF 按当前单元类型拆分，尾部剩余正文移到最后一个新单元。空行保留空段落 / 空项，不执行空项 Enter 退出，不识别列表前缀，段落不会因粘贴变成列表，列表项正文中的普通文字也原样保留。删除选区后的实际插入目标是列表项时，逐行丢弃复制生成的标记（`12. ` / `• `）：标记由结构重新编号，存进正文会显示两次；全选覆盖后目标变为段落，保留粘贴文本中的字面标记。单次粘贴或替换只产生一个历史单元。

例如粘贴 `1. A\n2. B` 到段落得到字面段落；粘贴 `A\nB` 到有序项得到同类型的两个结构项；把带标记的 `1. A\n2. B` 粘贴回列表，得到正文为 `A`、`B` 的结构项，编号按位置重新生成。

## IME

预编辑文本只属于临时展示，不进入 Document、持久化或撤销历史。候选确认的 Enter / Backspace 优先交给输入法，不能重复执行编辑命令。

提交是一次编辑；取消保持 composition 前文档与选区。关闭、失焦或切换便签时请求平台提交 / 取消，并等待最终事件再保存；不能把未提交候选当作已保存内容。

候选框跟随真实光标，滚动、Resize、DPI 变化后更新。若输入法没有正常结束组合，不能静默丢弃内容或永久卡住关闭；需保留窗口并提示重新处理。

Windows、X11、Wayland 的中文、日文、韩文输入路径均需真实环境验证，不能以普通文字能显示代替 IME 验收。
